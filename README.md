ChatApp

Aplicación de mensajería desarrollada como trabajo final para el curso de Frontend.

Descripción

ChatApp es una aplicación web inspirada en aplicaciones en WhatsApp. Permite visualizar conversaciones, buscar chats, enviar mensajes y consultar información de contactos y grupos.

Tecnologías utilizadas
React
Vite
JavaScript
CSS
React Router
Lucide React
Funcionalidades
Visualización de chats individuales y grupales.
Búsqueda de conversaciones.
Envío de mensajes.
Visualización de información de contactos.
Visualización de información de grupos y participantes.
Imágenes de perfil para contactos y participantes.
Navegación mediante React Router.
Uso de parámetros y search params.
Diseño responsive para distintos tamaños de pantalla.
Estructura del proyecto

El proyecto está organizado en diferentes carpetas para separar componentes, páginas, datos, contexto, hooks e imágenes.

components/: componentes reutilizables.
pages/: páginas principales de la aplicación.
context/: manejo del contexto del usuario.
hooks/: custom hooks.
data/: datos de chats y mensajes.
images/: imágenes utilizadas en la aplicación
